# nutley.us

A civic guide to Nutley, New Jersey — film of the dam at Kingsland Park, fading as you scroll.

Live: [https://trumanboyes.github.io/nutley.us/](https://trumanboyes.github.io/nutley.us/)

Custom domain: [nutley.us](https://nutley.us) (CNAME is in the repo; point DNS at `trumanboyes.github.io` and enable HTTPS in Pages settings).

## GitHub Pages

Static HTML at the repo root. Source: `main` / `/ (root)`, or the Actions workflow in `.github/workflows/pages.yml`.

## Contents

Parks, history, neighborhoods, schools, transit, and a township directory. This is an independent guide, not the official site ([nutleynj.org](https://www.nutleynj.org/)).
